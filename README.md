# LSEG Stock Bot

This is a basic chat bot application that allows user to select an exchange and then view the price of a particular stock that belongs to the exchange.

## Requirements

- Node.js version >= 20

## Installation steps

- Clone the repo locally.
- Navigate into the directory by `cd stock-bot`
- Run the following command

### For Yarn

`yarn install`

### For npm

`npm run install`

## Starting development server

To start the development server run the following command

`yarn dev` or `npm run dev`
